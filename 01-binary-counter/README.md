# 4-Bit Binary Counter

My first Arduino project. A simple 4-bit binary counter built using an Arduino Mega 2560 and four LEDs.

The counter displays binary numbers from `0000` to `1111` (decimal 0–15), with a short blinking interval between each count.

### Components
- Arduino Mega 2560
- 4 LEDs
- 4 resistors
- Jumper wires
- Breadboard

### Concepts Practiced
- Digital outputs (`pinMode()` and `digitalWrite()`)
- `for` loops
- Binary number representation
- Bitwise AND (`&`)
- Right shift (`>>`)
- Timing with `delay()`

### Learning Goal
Understand how binary numbers work and how individual bits can control physical outputs.
